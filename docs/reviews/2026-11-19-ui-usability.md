# 세션 매니저 UI·사용성 개선 검증

기준선은 `5fa52bb`이며, [승인 설계](../superpowers/specs/2026-11-19-ui-usability.md)와 [구현 계획](../superpowers/plans/2026-11-19-ui-usability.md)을 따른다.

- Node 59건, 삭제 흐름 검사 4건, Python 정리 3건, Rust 단위 139건과 통합 16건을 통과했다. 앞선 실행의 Windows 자식 프로세스 테스트는 간헐적으로 실패했으나 최종 직렬 전체 실행에서 통과했다.
- TypeScript와 Vite 프로덕션 빌드, 프런트엔드를 내장한 Windows 실행 파일을 검증했다. 기존 Browserslist 데이터 갱신 안내가 출력됐다.
- 격리 홈의 Codex CLI 0.170.0을 사용했다. Windows 앱의 좁은 창과 시험 터미널 전달, 체크박스 더블클릭 차단, 숨은 선택 제거와 확인 범위 재계산, 최근 1일 기준 삭제와 최근 자손 보호, Guardian 삭제, 폴더 사본 생성과 원본 유지, 사용자 지정 터미널 진단, 조회 오류와 삭제 재활성화를 확인했다.
- 별도 Chromium에서는 960×600 및 글자 150% 크기에서 고정 열·헤더, 정렬과 키보드 포커스 복귀를 확인했다. 실제 Google Drive 전송, 화면 낭독기, 사용자 세션 삭제와 Codex 대화 재개는 검증하지 않았다.
- 독립 검토에서 이전 확인 이벤트를 재사용할 수 있는 경쟁 조건을 발견했다. 재계산 시작·취소·실행 시 기존 미리보기의 승인을 동기적으로 무효화하고, 현재 미리보기 일치 여부를 검사하도록 수정했다. 회귀와 독립 재검토를 통과했다.

- 합성 세션 1,211개를 Windows 실행 파일로 펼친 뒤 가로·세로 스크롤에서 고정 헤더·제목·행 메뉴를 확인했다.
