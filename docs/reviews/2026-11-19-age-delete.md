# 기간 기준 일괄 삭제 검증.

## 결과.

- Rust 152개와 Node 41개, 삭제 흐름 검사 4개, TypeScript 검사와 Windows production 빌드가 통과했다.
- Codex CLI 0.170.0과 별도로 만든 Windows 테스트 홈을 사용했다. 7일 기본 선택에서 오래된 일반·보관·독립 자손만 체크되고 최근 기록과 그 부모가 제외됐다.
- 검색 결과가 비어 있는 상태에서 1일 기준으로 전체 등록 목록을 검사했다. 오래된 기록 4개만 삭제됐고 보호한 기록 3개는 남았다. 삭제 대상이 없는 확인창에서는 확인 버튼이 비활성화됐다.
- 첫 삭제 요청에서 다른 승인 대상의 작업 시각을 갱신하는 테스트를 실행했다. 보강 전에는 해당 테스트 기록이 제거됐고, 최종 빌드는 그 기록을 보존했다.
- 독립 리뷰에서 배치 중 재활동을 확인하는 문제를 발견했다. 각 요청 전 동일한 저장소를 읽기 전용으로 재검증하도록 수정한 뒤 재리뷰했다.

Codex의 등록 조회와 삭제 RPC는 별도의 연산이다. 모든 실제 삭제 검증은 새로 생성한 테스트 기록으로 수행했다.
