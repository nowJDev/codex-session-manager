# 세션 매니저 UI·사용성 개선

현장 점검에서 재현된 삭제 범위, 재개 이벤트, 목록 레이아웃, 상태와 접근성, 설정 편집 문제를 해결한다. 새 의존성이나 세션 저장 형식 변경 없이 기존 React·Radix·Tauri 구조를 사용한다.

- 삭제 확인은 백엔드가 계산한 실제 승인 ID를 제목·프로젝트·사유와 함께 25건 단위로 표시한다. 숨긴 선택을 빼면 범위를 다시 계산하고 자동 포함 자손은 계속 표시한다. 기간 보호와 Guardian 제약을 유지한다. 백엔드가 실행 전 계획을 거부하면 새 확인으로 이어진다. 실행 중 닫기는 막고, 요청 수·남은 시간·경과 시간·결과를 분리한다.
- 목록은 이름 영역과 행 작업을 가로로, 헤더를 세로로 고정한다. 제목으로 상세를 열고 제목 더블클릭 또는 명시적 명령으로만 재개한다. 1,120 CSS px 미만에서는 별도 상세 패널로 열며 동작을 상단에 둔다.
- 첫 로딩과 조회 실패, 기록 없음과 검색 결과 없음을 구분한다. 복구 버튼과 접는 기술 정보를 제공한다. 한국어 문구와 접근성 이름, 키보드 조작, 포커스 및 편집 실패 처리를 개선한다.
- 설정 진단은 편집값을 변경하지 않는다. 동기화 폴더의 최종 경로를 보여주고 공통 저장이 완료될 때 적용한다. 업로드는 지정 폴더에 사본을 만들며 로컬 원본을 유지한다.
- 테스트는 대상 Node 및 Rust 회귀, 빌드와 격리한 Windows 확인을 사용한다. 삭제 영향 확인과 외부 CLI 요청은 별개이므로 그 사이의 경쟁은 남는다.
