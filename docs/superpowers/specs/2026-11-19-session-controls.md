# 세션 트리, Guardian 삭제 및 Windows 재개.

## 승인 범위.

- 목록을 열면 각 가지를 접는다. 새로고침은 사용자가 펼친 기존 가지를 유지하고 새 가지를 접는다. 모두 펼치기·접기와 검색 중 조상 펼침을 지원한다. 검색을 끝내면 이전 펼침 상태를 복원한다.
- Guardian 전체 삭제 버튼은 검색·접기·보관 여부와 관계없이 최신 완전 목록에서 등록된 Guardian을 선택한다. Codex가 자손까지 삭제할 수 있으므로 다른 종류의 자손에 영향이 있는 대상은 확인 단계에서 제외하고 그 수와 사유를 알린다.
- 앱의 재개 버튼은 Windows Terminal에 PowerShell 명령과 작업 디렉터리의 리터럴 세미콜론을 이스케이프해서 넘긴다. PowerShell에서 실행할 때 기존 Codex 홈, 세션 ID와 플래그를 유지한다.

## 삭제 범위와 실패 조건.

카탈로그의 직접 부모 ID는 API 값을 우선한다. API에 관계가 없으면 같은 Codex 홈에서 확인한 등록 목록의 직접 부모를 보강한다. 삭제 계획, 실행 전 재조회와 실패 재시도에서 Guardian 제약을 유지한다. 승인 시점의 안전한 범위가 넓어지거나 종류가 바뀌면 실행을 중단한다. 실데이터 변경은 사용자가 앱의 확인창을 승인할 때 일어난다. 앱 서버의 영향 범위 검사와 삭제 RPC는 별도 호출이다.

## 검증.

초기 접기와 새로고침, 검색, 전체 선택은 실제 React 컴포넌트 테스트로 확인한다. 다른 종류의 자손, 보관된 Guardian, 재시도 및 누락된 API 부모 관계는 백엔드와 프런트 회귀에서 검증한다. Windows 빌드의 버튼 흐름은 새로 만든 별도 Codex 홈에서 확인한다.
