# 세션 삭제 진행 표시.

## 승인 범위.

삭제 확인창에서 삭제 범위 재확인, 삭제 요청 처리와 결과 확인 상태를 표시한다. 확인 후부터 창이 닫힐 때까지 경과 시간을 표시한다. 이미 승인된 대상과 현재 등록 목록을 비교하는 기존 검사 및 실패·재시도 흐름을 유지한다.

진행 건수는 중복된 부모와 자손을 정리한 후 Codex에 전송할 요청 수를 기준으로 표시한다. 응답을 받은 요청을 처리 건수에 포함한다. 최소 두 건의 응답 시간이 있고 이후 처리할 요청이 있으면 남은 요청 단계에 대한 예상 시간을 표시한다. 단일 부모 요청은 연쇄 자손 수와 관계없이 진행 건수와 경과 시간을 표시한다.

Rust에서 Tauri의 호출별 채널로 진행 상태를 전달한다. 기존 CLI 호출은 진행 상태 없이 같은 삭제 경로를 사용한다. 삭제 결과와 실제 제거 수는 삭제 후 등록 상태를 확인한 결과로 결정한다.

## 검증.

중복 및 계층 대상, 전송하지 않은 요청, 지연된 응답, 마지막 결과 확인, 영어·한국어 표시를 확인한다. 레지스트리와 실행 파일을 사용하는 검증에는 별도로 생성한 테스트 세션을 사용한다.
