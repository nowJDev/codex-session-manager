# 최근 활동을 보호하는 기간 기준 일괄 삭제.

## 화면과 승인.

상단에서 최근 1일·7일·30일 유지 중 하나를 고르고 일괄 삭제를 누른다. 앱을 새로 열었을 때 기본값은 7일이다. 앱은 검색과 접기에 관계없이 전체 등록 목록을 사용하며, 오래된 보관 세션도 후보에 포함한다. 서버가 확인한 삭제 후보만 체크한 뒤 기존 확인창을 연다. 취소하면 체크 상태와 그 기간 기준을 유지한다. 후보가 없으면 이유와 비활성화된 확인 버튼을 표시한다.

## 보호 조건.

기간은 버튼을 누른 시각에서 24시간 단위로 거슬러 계산한다. 경계 시각 이후에 작업했거나 시각을 확인할 수 없는 세션은 보호한다. 보호 세션을 함께 지우는 조상도 대상에서 제외한다. 오래된 자손 자체의 하위에 보호 세션이 없으면 독립적으로 삭제할 수 있다.

기간 기준을 승인된 대상과 재시도에 보존한다. 삭제 실행 전 전체 목록으로 활동과 영향 범위를 다시 확인한다. 이어서 일괄 실행 중에는 각 요청 전 동일한 Codex 등록 저장소를 읽어 변경된 활동과 자손을 점검한다. 실제 제거는 Codex API가 수행하고 완료 후 등록 부재를 다시 확인한다. 마지막 활동 조회와 외부 API 호출은 별도의 연산이다.

## 검증.

단위 회귀에서 정확한 시각 경계, 미상 시각, 자손 관계, 확인 이후 및 요청 사이에 다시 작업하는 경우를 검사한다. 별도 Codex 홈과 생성한 세션을 사용해 Windows 앱에서 자동 체크부터 실제 삭제 결과까지 확인한다.
