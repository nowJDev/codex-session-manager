# v0.5.12 릴리스 실행 계획.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 사용자가 확인한 세션 조회·삭제 수정 버전을 GitHub의 최신 Windows 릴리스로 발행한다.

**Architecture:** 기존 태그 기반 `.github/workflows/release.yml`과 GitHub에 등록된 Tauri 서명 설정을 그대로 사용한다. 기능 코드는 바꾸지 않고 버전·변경 내역·검증 기록만 갱신한다. 사용자 요청으로 main 통합·푸시·발행·임시 산출물 정리까지 수행한다.

**Tech Stack:** Git, GitHub CLI, GitHub Actions, Tauri 2, Cargo, pnpm, PowerShell.

---

대상 파일은 `package.json`, `src-tauri/Cargo.toml`, 자동 생성되는 `src-tauri/Cargo.lock`, `src-tauri/tauri.conf.json`, `CHANGELOG.md`, `docs/current-state.md`, `docs/release-qa.md`이다.

- [x] 버전 세 곳을 0.5.12로 올리고 `cargo update --offline --package codex-session-manager`로 루트 패키지 lock 항목만 갱신했다. 이전 lock과 구조를 비교해 의존성 버전 불변을 확인했다.
- [x] 변경 내역에 등록 세션·ID 삭제 검증·기존 트리 지원 유지와 검증 제한을 기록했다.
- [x] 세 manifest와 lock의 버전 일치, Node 18개·삭제 검사 4개, 프런트 production build와 전체 diff를 확인했다. 기능 코드의 Windows Rust 122개 통과 증거는 직전 커밋에 있다.
- [x] 검증된 릴리스 준비 변경을 `8cfa809`로 커밋했다.

- [x] Release 실행 41374695666의 Windows 빌드·공개 전환 성공을 확인했다. push 후 자동 실행이 생성되지 않아 기존 workflow_dispatch를 사용했다. main CI 자동 실행은 생성되지 않아 CI 통과로 보고하지 않는다.

- [x] 다운로드한 네 자산의 크기·SHA256, 포터블 exe 버전 0.5.12, updater 플랫폼·URL·서명과 공개 최신 URL의 HTTP 200·해시 일치를 확인했다. 공개키 서명 검증과 변조 거부도 통과했다.
