# 현재 소스 상태.

현재 소스·로컬 검증 빌드는 v0.5.13이며 전체 지속 세션 표시와 부모·서브 트리 복구를 포함한다. 추가 의존성은 없다. 이번 작업에서 공개 릴리스를 발행하지 않았으며 기존 v0.5.12 발행 기록과 다운로드 링크를 유지한다. 상세 설계는 `superpowers/specs/2026-11-17-full-session-tree-design.md`, 실행 계획은 `superpowers/plans/2026-11-17-full-session-tree.md`, 검증과 제한은 `reviews/2026-11-17-full-session-tree.md`를 따른다.

같은 Codex 홈의 DB 등록 ID를 읽기 전용으로 대조하고 기본·조상별·metadata-only 조회로 전체 목록을 구성한다. 등록 세션은 JSONL 유무와 무관하게 확인하며 실제 직접 부모 관계를 보존한다. Guardian·요약용·기존 제외 경로의 기록도 처음부터 표시한다. 숨김 체크와 스캔 제외 경로 편집 UI는 제거했고 기존 설정 값과 자동요약 실행 제외 정책은 보존했다. SQLite·인덱스를 직접 수정하지 않는다. paginated 파일 백업은 지원하지 않으며 실제 legacy 파일의 ID·형식을 검증한다.

목록·삭제 영향·삭제 전후 확인은 공통 SessionSnapshot 완전성 계약을 사용한다. 추가 파일·클라우드 병합까지 하나의 60초 예산을 공유하고 시간 초과·누락·조회 실패·미지원 DB 스키마에서는 확보한 행과 오류를 보존하며 삭제를 차단한다. 갱신 실패 시 이전 완전 목록과 선택을 유지한다. 첫 불완전 조회는 부분 행과 누락·오류를 표시한다. OS 파일 I/O 자체의 원자적 강제 중단과 API·DB의 원자적 스냅샷은 보장하지 않는다.

트리는 접힌 상태로 시작하고 모두 펼치기·접기, 종류 배지와 상세 부모·깊이를 제공한다. 검색은 일치 세션과 조상을 펼치고 검색을 지우면 이전 펼침 상태로 돌아간다. 새로고침에서도 기존 가지의 펼침·선택을 유지하며 새 가지는 접힌 상태로 나타난다. 전체 선택은 논리 표시 행의 등록 세션을 대상으로 하며 전체·작업 서브·표시·선택·선택 중 표시 수를 구분한다.

Guardian 전체 삭제는 보관된 항목을 포함한 등록 Guardian을 선택한다. API가 직접 부모를 생략하면 같은 Codex 홈의 등록 목록에서 확인한 관계를 보강한다. 확인과 실행 전 조회에서 다른 종류에 영향을 주는 가지를 검사하고, 재시도에도 같은 제약을 적용한다. Windows Terminal로 세션을 재개할 때는 PowerShell에 넘기는 리터럴 세미콜론을 이스케이프한다.

삭제 확인창은 확인 후 경과 시간, 처리한 Codex 삭제 요청 수, 최종 결과 확인 상태를 표시한다. 완료된 요청이 두 건 이상이고 추가 요청이 있을 때 삭제 요청 처리 단계의 남은 시간을 추정한다. 하나의 부모 요청에 하위 기록이 여러 개 있는 경우에도 요청 한 건으로 표시한다.

삭제 진행 창에서 요청 건수와 남은 시간, 경과 시간은 각 줄에 표시한다. 2,585초는 43분 5초와 같이 표시한다.

기간 기준 일괄 삭제는 최근 1일·7일·30일을 유지하고 오래된 등록 세션만 자동 체크한다. 기본 선택은 7일이다. 검색과 트리 접기 상태는 범위를 바꾸지 않는다. 최근 기록과 날짜 미확인 기록, 해당 기록과 함께 삭제되는 조상은 보호한다. 기간 조건은 취소 후 체크된 대상과 실패 재시도에도 유지한다.

Windows/Codex CLI 0.169.0에서 정상 권한 Rust 141개, Node 36개와 삭제 VM 회귀 4개, 타입 검사·기본 Vite production build·정식 Tauri CLI production 빌드를 확인했다. 0.166.0은 응답 fixture 호환만 검사했으며 이번 작업에서 실제 바이너리를 실행하지 않았다. Windows shim 프로세스 트리 종료 테스트의 제한 권한 실패는 정상 권한 전체 통과와 구분한다. 기존 Browserslist 데이터 경고는 남아 있다.

실제 production 네이티브 앱은 원본 DB의 읽기 전용 SQLite backup을 사용한 별도 홈·WebView 프로필에서 검증했다. 복사본 등록 2,287개와 작업 서브 385개, 초기 표시 2,287개 및 직접 부모 정합을 확인했다. 검색·전체 선택·키보드 접기·상세 유지·새로고침 접기 유지·수천 행 스크롤과 실제 IPC 정상 흐름을 확인했다. 전체 선택 482ms, 모두 펼치기 3,639ms, 스크롤 두 requestAnimationFrame 23.5ms는 첫 실행의 관측값이다. 읽기 전용 프록시로 삭제·보관·모델 실행을 차단했으며 원본 세션·설정·JSONL을 수정하거나 삭제하지 않았다. 실제 RPC 조회에 한 번 오류를 주입한 후 헤더의 표시 2개·선택 2개 보존, 삭제 버튼 비활성화와 새로고침 후 활성화·오류 해제를 확인했다. 오류 주입부터 UI 확인까지 60,552ms였으며 수집의 60초 예산과 이후 UI 처리를 포함한다. 이 네이티브 검사는 실패 중 테이블 viewport 가시성까지 측정하지 않았다.

이후 별도 Chrome production DOM에서 긴 오류로 목록 높이가 0이 되는 문제를 재현하고 수정했다. 오류 영역은 최대 25vh와 독립 스크롤·키보드 포커스를 제공한다. 높이 1,000px 화면에서 목록 688.5px·오류 영역 250px, 전체 오류 52,949자 보존·표시 행 2개·포커스·500px 스크롤을 확인했다.

Windows 읽기 전용 임시 파일 정리는 소유 경계·기존 OS 오류 전달을 보존하는 수정 후 Python unittest 3개 RED→GREEN과 전체 통과를 확인했다. 이전 실패 검사에서 남은 소유 임시 루트도 안전하게 정리했다. 이 정리는 전체 작업 worktree·브랜치 정리 완료를 의미하지 않는다. 오류 영역·임시 정리 수정 이후 실제 CLI 0.169.0의 전체 API 재검증과 cleanup이 종료 코드 0으로 통과했으며 생성 임시 루트가 남지 않았음을 확인했다. 정식 Tauri production 재빌드도 custom-protocol을 포함해 종료 코드 0, 100,335ms로 완료했다. 최종 실행 파일의 네이티브 정상·실패 회복 흐름 재검증도 종료 코드 0, 108,424ms로 통과했다. 최종 실행은 등록 2,287개·작업 서브 385개, 전체 선택 668ms·전체 펼침 5,466ms·스크롤 두 requestAnimationFrame 28.2ms·실패 확인 28,622ms를 기록했다.

백엔드와 프런트 독립 리뷰를 승인받았다. 전체 브랜치 최종 리뷰는 `35336b5` 기준 Ready to merge Yes이며 Critical 0건·Important 0건·Minor 1건이었다. Minor는 완료된 네이티브 검증을 대기로 표시한 문서 상태 불일치이며 이번 단일 문서 수정에서 바로잡았다. 기존 판단 3건과 리뷰 범위 제외 8건의 수용 이유·비용은 검증 기록에 보존했다. 제품 suite와 네이티브 실행은 반복하지 않고 문서만 검증했다. 문서 수정의 scoped 재리뷰도 승인됐다. 로컬 main 통합 후 Rust 141개·Node 36개·삭제 4개·Python 3개와 타입 검사가 다시 통과했다. 바탕화면 바로가기 대상 실행 파일을 검증된 0.5.13으로 교체하고 PE 버전·SHA-256 일치를 확인했으며 임시 자료·worktree·브랜치 정리를 완료했다. 실제 사용자 세션 삭제·네이티브 삭제 실행, 실제 모델 요약과 계정 간 클라우드 동기화 쓰기는 이번에 수행하지 않았다.

이전 v0.5.12 공개 릴리스 발행과 자산 해시·updater 서명·바로가기 갱신·main 통합·정리 기록은 `superpowers/plans/2026-11-02-v0.5.12-release.md`와 `release-qa.md`에 보존한다. 이 기록은 이번 작업에서 원격 최신 상태를 다시 조회했다는 의미가 아니다. 이전 API 검증과 한계는 `reviews/2026-11-02-paginated-sessions.md`를 따른다.

README의 제품 소개형 구조, 공개 다운로드 링크와 v0.5.12 샘플 화면은 유지했다. 이번 변경의 전체 표시·완전성·호환 범위만 갱신했으며 이전 README 화면 검증 기록은 `reviews/2026-11-02-readme.md`에 보존한다.

2026-11-17 후속 요청으로 전체 커밋의 origin/main 반영을 승인받았다. fetch·prune 후 로컬 main은 원격보다 9커밋 앞서고 뒤처진 커밋·추가 병합 대상은 없었다. 중간 debug 산출물 약 5.27GiB와 빈 임시 디렉터리·Cargo 캐시 메타데이터를 정리했다. 현재 바로가기가 참조하는 0.5.13 release GUI·CLI·리소스와 node_modules는 보존하고 실행 파일 해시·PE 버전을 재확인했다. 상세 경계와 근거는 `reviews/2026-11-17-full-session-tree.md`의 후속 정리 기록을 따른다.

삭제 확인의 제목·포함 사유와 숨은 선택 재계산, 재개 안전성, 목록 고정 열과 키보드 정렬, 좁은 창의 상세, 오류 복구와 설정 저장을 개선했다. [상세 검증](reviews/2026-11-19-ui-usability.md)에 격리 실행 결과와 범위를 기록했다. 검증한 로컬 실행 파일은 `src-tauri/target/ui-usability/codex-session-manager.exe`에 있다.
